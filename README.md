# Krónikás

A system-agnostic RPG campaign and narrative management application for Game Masters, developed under the Akihabarai Könyvespolc brand.

Planned platforms: Windows and Android. The project is currently in Phase 0 (planning); no usable release is available yet.

This public repository contains product development materials only. Actual campaign and adventure data are stored separately.
