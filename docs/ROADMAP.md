# Roadmap

Tervezett sorrend. A munkacsomagokat és ellenőrzési feltételeket az [implementációs terv](IMPLEMENTATION_PLAN.md) részletezi.

- Phase 0: use case-ek, követelmények, domain/adatmodell, technológiai vizsgálat, architektúra, tesztstratégia és implementációs terv.
- Phase 1: CORE, kampány/kaland/session/mérföldkő/esemény, állapot, lokális mentés, automatizált tesztek.
- Phase 2: repository konfiguráció, hitelesítés, szinkronizáció, offline működés, konfliktuskezelés.
- Phase 3: Windows/Android UI, kalandválasztó, tervező, aktív session, sync státusz.
- Phase 4: narratív összefoglaló, publikálható információk, opcionális LLM, szerkesztés és jóváhagyás.
- Phase 5: Discord webhook, publikációs állapot, hibák és ismételt küldés.
