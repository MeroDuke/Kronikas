# Krónikás

Az Akihabarai Könyvespolc fejlesztés alatt álló, szerepjátékrendszer-független kaland- és kampánymenedzsere mesélőknek.

A mesélő mesél. A Krónikás megőrzi a történetet.

Tervezett célplatformok: Windows és Android. Jelenlegi állapot: tervezés (Phase 0), még nincs használható kiadás. A publikus repository kizárólag a termék fejlesztését szolgálja; valódi kampányadatokat nem tárol.
